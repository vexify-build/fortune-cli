# Fortune CLI 🎱

> A tiny but delightful CLI that spits out random fortunes, jokes, quotes, or ASCII art.

## Features

- 🎱 Random fortunes / wise sayings
- 😂 Dad jokes
- 💡 Developer/programming quotes
- 🎨 Random ASCII art
- 🌈 Colorful output with `cfonts`

## Install

```bash
npm install -g fortune-cli
```

## Usage

```bash
fortune              # random everything
fortune --type fortune
fortune --type joke
fortune --type quote
fortune --type ascii
fortune -n 5         # generate 5 at once
```
